Space Ball

## Theme

I interpreted the theme as a game that requires only one keyboard button to be able to beat.

## Game Play

Objective

Get to the end of the level without touching any red zones


Game-play instructions

Press space to add force to the ball

Dont touch the red

## What did you

Struggles or surprises you encountered during the development of the game

One thing i really struggled with was getting the camera to work properly. It was hard to get it to follow properly as its default settings had it spinning with the ball and it was really disorientating. I had to test all the settings to figure it out.

## Special Focus

What is your special focus? What did you do for it? How would you rate your own effort? 1-5. (I will agree or disagree with this sentiment, but I want to know what you thought)

My special focus was mechanics. I wanted to create a game that uses one button but still has some sort of skill and gimmick to it. The nature of the game is that you dont know whats coming next so you will most likely die a few times. I liked this idea of a die and retry mechanic. id give my effort a 3 out of 5 as it was fun to make but i didn't get to put too much time into it or really expand upon the idea.
